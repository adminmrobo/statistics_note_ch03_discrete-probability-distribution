성공과 실패를 세는 일곱 가지 방법

핵심 질문 — 똑같은 "성공 아니면 실패" 실험인데, 왜 "몇 번 성공했나"와 "언제 처음 성공했나"는 서로 다른 분포가 될까?

노란 점선 밑줄을 누르거나 마우스를 올리면 뜻이 나옵니다. 오른쪽 아래 도우미로 밑줄을 핵심 → 전체 → 끄기로 바꿀 수 있어요. 이 페이지는 시리즈의 첫 편입니다. 확률질량함수(막대 높이 = 확률, 합 = 1)라는 말만 알면 충분하고, 재는 값의 밀도함수는 다음 편 1.2에서 이어집니다. 이 페이지의 모든 확률값은 페이지 코드가 공식으로 직접 계산하고, 시뮬레이션은 시드를 고정한 설명용 모형입니다. 숫자 요약의 각주 번호는 맨 아래 출처 표를 가리킵니다.

왜 이 주제인가

1현장의 숫자는 대개 센다

불량품 개수, 시간당 방문 고객 수, 첫 고장까지 돌린 횟수처럼 품질·서비스·신뢰성 데이터의 상당수는 0, 1, 2, … 로 세는 값입니다.

2질문이 분포를 고른다

3코드 함수마다 세는 법이 다르다

R의 dgeom은 첫 성공 전 실패 수를, 파이썬 scipy.stats.geom은 첫 성공까지 시행 수를 셉니다. 초기하분포는 두 언어에서 인자 이름 n의 뜻이 다릅니다. 무엇을 세는지 알아야 결과를 바로 읽습니다.

1한 번

베르누이 시행 — 성공 아니면 실패, 딱 한 번

모델: P(X = 1) = p, P(X = 0) = 1 − p연구실: 시험관 하나를 검사해 합격·불합격

연구실에서는

시험관 하나를 검사기에 넣으면 결과는 합격 아니면 불합격 둘뿐입니다. 관심 있는 쪽(여기서는 불합격)을 1, 나머지를 0으로 적습니다. 검사를 여러 번 해도 시험관마다 불합격 확률이 같고, 앞 결과가 뒤 결과에 영향을 주지 않는다고 봅니다.

확률 모형에서는

결과가 두 가지뿐이고(1·0), 시행끼리 독립이며, 성공 확률 p가 매번 같은 시행이 베르누이 시행입니다. 확률질량함수는 P(X = x) = px(1 − p)1−x, x ∈ {0, 1}. 기대값 E[X] = p, 분산 Var[X] = p(1 − p).

예

행동으로 보기 — 하루가 시험관을 하나씩 검사한다 (빨강 = 불합격 1)

풀이 — 베르누이 시행 읽는 법

  1. 결과를 두 가지로 나누고, 관심 있는 쪽을 "성공" = 1로 정한다. 불량품을 찾는 검사라면 불량이 "성공"이다. 이름일 뿐 좋은 일이라는 뜻이 아니다.
  2. 성공 확률 p 하나로 분포 전체가 정해진다: P(X = 1) = p, P(X = 0) = 1 − p.
  3. 기대값은 0 × (1 − p) + 1 × p = p. 많이 검사하면 1의 비율이 p 근처로 모인다.
  4. 분산 p(1 − p)는 p = 0.5에서 가장 크다(0.25). p가 0이나 1에 가까우면 결과가 거의 정해져 있어 흩어짐이 작다. 동전(0.5)은 0.25, 품질검사(0.01)는 0.0099.

이 칸의 한계: 시행이 딱 한 번입니다. 시험관 20개를 한 묶음으로 검사하면 "불합격이 몇 개 나올까?"를 알고 싶어지는데, 베르누이 하나로는 답할 수 없습니다.

수식으로 보기

E[X] = Σ x·P(X = x) = p, E[X²] = 0²(1 − p) + 1²·p = p이므로 Var[X] = E[X²] − (E[X])² = p − p² = p(1 − p).

p(1 − p)를 p로 미분하면 1 − 2p = 0 → p = 0.5에서 최대 0.25. 그래서 "결과가 가장 불확실한 동전"이 분산이 가장 큽니다.

언어 모델 답변 하나를 "정답/오답"으로 채점하면 베르누이 시행입니다. 평가 세트의 정확도는 이 베르누이 결과들의 평균, 곧 p를 추정한 값입니다.

비유의 한계: 문항마다 난이도가 달라 "모든 시행의 p가 같다"는 가정이 실제로는 잘 맞지 않습니다.

2n번 중

이항분포 — n번 중 몇 번 성공할까

모델: X ~ B(n, p), P(X = k) = C(n, k) pk(1 − p)n−k연구실: 시험관 n개 한 로트를 검사해 불합격 수 세기

연구실에서는

불량률 5%인 공정에서 시험관 10개를 한 로트로 뽑아 검사합니다. 시험관마다 같은 확률로 독립적으로 불량이 나오면, 로트 안 불량 개수는 0개부터 10개까지 퍼집니다. 그 퍼짐 모양이 이항분포입니다.

확률 모형에서는

같은 베르누이 시행을 n번 독립으로 반복할 때 성공 횟수 X가 이항분포 B(n, p)를 따릅니다. C(n, k)는 n번 중 성공할 k자리를 고르는 경우의 수(조합)입니다. E[X] = np, Var[X] = np(1 − p). n = 1이면 베르누이입니다.

풀이 — 이항 확률을 세 조각으로

  1. 한 가지 순서의 확률: 예를 들어 "성공·성공·성공·실패"는 0.7 × 0.7 × 0.7 × 0.3 = 0.7³ × 0.3¹. 독립이라 곱한다.
  2. 순서의 개수: 4번 중 성공 3자리를 고르는 방법은 C(4, 3) = 4!/(3!·1!) = 4가지. 순서마다 확률이 같다.
  3. 곱하기: P(X = 3) = 4 × 0.343 × 0.3 = 0.4116.
  4. 누적·여사건: P(X ≤ 3) = 1 − P(X = 4) = 1 − 0.2401 = 0.7599. "적어도 1개"는 1 − P(X = 0): 불량 5%, 10개면 1 − 0.95¹⁰ ≈ 0.401.
  5. 모양: p = 0.5면 대칭, p < 0.5면 오른쪽으로 꼬리가 길고(왼쪽에 몰림), p > 0.5면 반대. 가장 높은 막대(최빈값)는 대개 ⌊(n + 1)p⌋. n이 커지면 종 모양에 가까워진다.

이 칸의 한계: 시행 횟수 n을 미리 정해야 합니다. "첫 불량이 몇 번째 시험관에서 나올까?"는 몇 번 검사할지 정해져 있지 않아, 이항분포로는 물을 수 없습니다.

수식으로 보기

X = X1 + … + Xn(각 Xi는 베르누이)로 쓰면 E[X] = np, 독립이므로 Var[X] = Σ Var[Xi] = np(1 − p). 동전(p = 0.5)을 100번 던지면 기대값 50, 분산 25, 표준편차 5.

P(X ≥ k) = 1 − Σi=0k−1 C(n, i) pi(1 − p)n−i. 만족 확률 0.75로 20명을 조사하면 P(X ≥ 15) = 1 − P(X ≤ 14) ≈ 0.617입니다(위 예 버튼으로 확인).

현장에 옮기면

샘플링 합격 판정: 로트에서 n개를 뽑아 불량이 c개 이하면 합격. 로트 불량률이 p일 때 합격할 확률은 P(X ≤ c)이고, p를 바꿔 가며 그린 곡선이 검사 방식의 성능(OC 곡선)입니다. 불량률을 감시하는 p 관리도도 이항분포를 바탕으로 합니다.

비유의 한계: 로트가 작으면 뽑은 시료를 되돌려 놓지 않는 효과가 커서 초기하분포(⑤칸)가 더 정확합니다.

3기다리기

기하분포와 음이항분포 — 몇 번째에 성공할까

모델: P(X = k) = (1 − p)k−1p · C(k−1, r−1) pr(1 − p)k−r연구실: 반응이 나올 때까지 실험 반복

연구실에서는

시약 반응이 나올 때까지 같은 실험을 반복합니다. 반응 확률이 매번 0.2라면 첫 반응은 몇 번째 실험에서 나올까요? 두 번째 반응까지는 몇 번이 걸릴까요? 이번에는 횟수 n이 정해져 있지 않고, 성공이 나올 때까지 셉니다.

확률 모형에서는

첫 성공까지의 시행 횟수 X는 기하분포: P(X = k) = (1 − p)k−1p, k = 1, 2, …, E[X] = 1/p, Var[X] = (1 − p)/p². r번째 성공까지는 음이항분포: P(X = k) = C(k−1, r−1) pr(1 − p)k−r, k ≥ r, E[X] = r/p, Var[X] = r(1 − p)/p². r = 1이면 기하분포입니다.

행동으로 보기 — 무기억성: "이미 3번 실패한 줄"만 골라도 남은 대기 모양이 같다

풀이 — 기다리는 횟수를 세는 법

  1. 기하분포: "k번째에 처음 성공" = 앞의 k − 1번은 모두 실패, k번째는 성공. 그래서 (1 − p)k−1 × p. p = 0.2, k = 4면 0.8³ × 0.2 = 0.512 × 0.2 = 0.1024.
  2. 막대 모양: k = 1이 늘 가장 높고, 오른쪽으로 갈수록 (1 − p)배씩 줄어든다. 평균 1/p: p = 0.2면 평균 5번, 주사위 6(p = 1/6)이면 평균 6번.
  3. 무기억성: 이미 m번 실패했어도, 앞으로 첫 성공까지 남은 횟수의 분포는 처음과 똑같다. "이번엔 나올 때가 됐다"는 생각은 독립 시행에서는 틀리다. 이산분포 중 이 성질을 가진 것은 기하분포뿐이다.
  4. 음이항분포: r번째 성공이 정확히 k번째라면, 마지막 시행은 반드시 성공이고 앞의 k − 1번 중 r − 1번이 성공. 자리 고르기 C(k−1, r−1). p = 0.3, r = 2, k = 5: C(4, 1) × 0.3² × 0.7³ = 4 × 0.09 × 0.343 = 0.12348.

이 칸의 한계: 시행이 1번, 2번… 으로 나뉘어 있어야 셀 수 있습니다. "1시간 동안 들어온 택배 수"처럼 아무 순간에나 일어나는 사건은 시행 수를 셀 수가 없습니다.

수식으로 보기 — 두 가지 세는 법

기하분포는 "첫 성공까지 시행 수"(k = 1, 2, …, 평균 1/p)와 "첫 성공 전 실패 수"(k = 0, 1, …, 평균 (1 − p)/p) 두 가지로 정의됩니다. 분산은 둘 다 (1 − p)/p²입니다. 이 페이지는 시행 수를 씁니다.

무기억성: P(X > m + j | X > m) = (1 − p)m+j/(1 − p)m = (1 − p)j = P(X > j).

음이항의 시행 수 = 실패 수 + r이므로 평균은 r/p, 분산은 실패 수 버전과 같은 r(1 − p)/p². r = 2, p = 0.3이면 평균 6.67번.

Money-Robo

세 번 연속 실패했으면 이번엔 성공 확률이 올라가 있어야 공평하지. …분홍 막대가 초록 막대랑 똑같다고?

생성 AI로 치면

조건에 맞는 답이 나올 때까지 다시 생성한다면, 한 번에 통과할 확률이 p일 때 필요한 호출 횟수는 기하분포를 따르고 평균 1/p번입니다. 통과율 0.25면 평균 4번 호출하므로 비용도 4배로 잡습니다.

비유의 한계: 같은 프롬프트로 다시 생성한 결과는 서로 닮기 쉬워, 시행이 완전히 독립이라는 가정이 깨질 수 있습니다.

4단위 시간

포아송분포 — 한 시간에 몇 번 일어날까

모델: P(X = k) = λke−λ/k!, E = Var = λ연구실: 시간당 도착하는 시료 택배

연구실에서는

연구실 문 앞 택배함에 시료가 아무 때나 도착합니다. 평균은 5분에 2개. 도착은 서로 독립이고, 아주 짧은 순간에 두 개가 동시에 올 일은 거의 없습니다. 5분 동안 도착한 개수를 세면 포아송분포를 따릅니다.

확률 모형에서는

단위 시간(또는 공간)에 독립적으로 일어나는 사건의 횟수 X가 포아송분포를 따릅니다. λ는 단위당 평균 횟수이고, 평균과 분산이 모두 λ입니다. 이항분포 B(n, p)에서 n → ∞, p → 0, np = λ로 둔 극한이기도 합니다.

풀이 — 포아송은 "잘게 쪼갠 이항"

  1. 5분을 n칸으로 쪼개고, 칸마다 "택배가 왔다/안 왔다"를 베르누이로 본다. 칸당 확률을 λ/n으로 두면 평균은 n × λ/n = λ로 고정된다.
  2. 칸을 잘게 쪼갤수록(n ↑, p ↓) B(n, λ/n)이 포아송(λ)에 가까워진다. 위 패널에서 n을 5 → 500으로 바꿔 분홍 윤곽이 초록 막대에 붙는 것을 보세요.
  3. λ = 3이면 P(X = 0) ≈ 0.0498, P(X = 1) ≈ 0.1494, P(X = 2) = P(X = 3) ≈ 0.2240, P(X = 4) ≈ 0.1680, P(X = 5) ≈ 0.1008.
  4. 평균 = 분산 = λ. 실제 데이터의 분산이 평균보다 훨씬 크면 "독립·일정한 비율" 가정을 의심한다. λ가 커지면 막대가 오른쪽으로 옮겨 가며 종 모양에 가까워진다.

이 칸의 한계: 시행이 모두 독립이고 확률이 일정하다고 가정합니다. 상자에서 시료를 꺼내 검사하고 되돌려 놓지 않으면, 꺼낼 때마다 남은 불량 비율이 바뀌어 이 가정이 깨집니다.

수식으로 보기 — 이항에서 포아송으로

p = λ/n을 넣으면 C(n, k)(λ/n)k(1 − λ/n)n−k = (λk/k!) · [n(n−1)…(n−k+1)/nk] · (1 − λ/n)n · (1 − λ/n)−k. n → ∞에서 가운데 대괄호 → 1, (1 − λ/n)n → e−λ, 마지막 항 → 1. 남는 것이 λke−λ/k!입니다.

실무에서는 n이 크고 p가 작을 때(예: n ≥ 20, p ≤ 0.05) 이항 대신 포아송(λ = np)으로 근사하곤 합니다.

박사

박사의 한 줄: 포아송은 칸이 무한히 많고 칸마다 확률이 아주 작은 이항이에요. 그래서 "드문 사건의 법칙"이라고도 불러요.

현장에 옮기면

콜센터·창구 인력 배치: 시간당 평균 문의가 λ건이면, 상담원이 감당할 수 있는 c건을 넘을 확률 P(X > c)로 필요한 인원을 정합니다. 보험의 사고 건수, 문서 한 쪽의 오타 수, 설비의 월간 고장 건수도 같은 방식으로 다룹니다.

비유의 한계: 점심시간처럼 시간대마다 λ가 달라지면 하루 전체를 하나의 포아송으로 볼 수 없어, 시간대를 나눠 따로 λ를 잡아야 합니다.

5비복원

초기하분포와 다항분포 — 이항의 두 가정을 풀면

모델: C(K, k)C(N−K, n−k)/C(N, n) · n!/(x1!…xk!) p1x1…pkxk연구실: 봉인 상자에서 꺼내기 · 세 등급 분류

연구실에서는

봉인 상자에 시험관 N개, 그중 불량 K개. n개를 꺼내 검사하고 되돌려 놓지 않습니다. 불량을 하나 꺼내면 남은 상자의 불량 비율이 줄어, 다음 시험관의 불량 확률이 바뀝니다(초기하). 한편 검사 결과를 합격·재검·불합격 세 등급으로 나누면, 결과가 둘이 아니라 셋입니다(다항).

확률 모형에서는

초기하분포: P(X = k) = C(K, k)C(N−K, n−k)/C(N, n), E[X] = nK/N, Var[X] = n(K/N)(1 − K/N)(N − n)/(N − 1). 다항분포: 결과가 k가지(확률 p1, …, pk, 합 1)인 시행을 n번 했을 때 결과별 횟수의 결합분포. E(Xi) = npi, Var(Xi) = npi(1 − pi).

실험

풀이 — 이항의 가정 하나씩 풀기

  1. 독립을 풀면 초기하: 꺼낸 것을 되돌려 놓지 않으면 시행마다 확률이 바뀐다. 바둑돌 예: C(5, 2)·C(5, 3)/C(10, 5) = 10 × 10/252 = 0.3968. 전체 분포는 0.004, 0.099, 0.397, 0.397, 0.099, 0.004.
  2. 평균은 같고 분산은 작다: 초기하 평균 nK/N은 이항 B(n, K/N)과 같다. 분산은 (N − n)/(N − 1)배로 줄어든다. 뽑을수록 남은 상자에 대한 불확실성이 줄기 때문이다. n = N(전부 검사)이면 분산 0: 카드 20장(앞면 10장)을 모두 뽑으면 앞면은 언제나 10장. 같은 20번을 되돌려 놓으며 뽑으면 B(20, 0.5)라 표준편차 √5 ≈ 2.24.
  3. N이 n보다 훨씬 크면 이항과 거의 같다: 위 패널에서 N을 200으로 올리면 초록 막대가 분홍 윤곽에 붙는다.
  4. 결과 둘을 풀면 다항: 범주가 k개면 n!/(x1!…xk!)가 "나열 방법의 수", p1x1…pkxk가 "한 나열의 확률". 범주 하나만 보면 Xi ~ B(n, pi)다. 주사위 예는 151,200/6¹⁰ ≈ 0.0025.

이 칸의 한계: 일곱 분포는 모두 0, 1, 2, … 로 세는 값입니다. 키·무게처럼 재는 값, 그리고 n이 커질 때 이항분포가 닮아 가는 종 모양은 연속분포인 정규분포의 몫입니다. 재는 값에 확률을 붙이는 법은 다음 편 1.2에서 다룹니다.

수식으로 보기

초기하 분산: Var[X] = n·(K/N)·((N − K)/N)·((N − n)/(N − 1)). 마지막 인수가 유한 모집단 보정입니다. TV 예(N = 100, K = 5, n = 10): 평균 0.5, 분산 0.4318, P(X = 3) ≈ 0.0064.

다항분포의 공분산 Cov(Xi, Xj) = −npipj(i ≠ j). 총 횟수 n이 고정이라 한 범주가 늘면 다른 범주가 줄어 늘 음수입니다.
